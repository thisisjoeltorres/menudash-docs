# Aplicativo Web para el Registro y Gestión de Pedidos en Tiempo Real

Proyecto de aula para la asignatura **Desarrollo Orientado a Plataformas** en la **Universidad de Pamplona**. 

Esta aplicación web está diseñada para optimizar la toma de comandas y la comunicación en tiempo real entre el salón (clientes/meseros), la cocina y la administración en restaurantes del Área Metropolitana de Cúcuta.

## 🚀 Funcionalidades Principales

* **Acceso Multi-rol:**
  * **Cliente:** Acceso directo para realizar pedidos ingresando únicamente nombre y número de teléfono.
  * **Mesero:** Registro rápido de comandas por mesa desde dispositivos móviles.
  * **Cocina:** Panel en tiempo real para visualizar, aceptar, rechazar y actualizar el estado de los pedidos ("En preparación" / "Listo").
  * **Administrador:** Panel de control con estadísticas en tiempo real sobre ventas, productos más vendidos e historial filtrado por fechas.
